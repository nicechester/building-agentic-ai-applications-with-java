# Appendix C: Example Projects

Example projects to learn from.

## Bible-AI

**Location:** `https://github.com/nicechester/bible-ai`

**Features:**
- Korean Revised Version Bible
- Reverse RAG pattern
- Session management
- Mermaid diagram support

**Key Files:**
- `BibleAgent.java` - Agent implementation
- `BibleTools.java` - Tool definitions
- `RAGConfig.java` - RAG setup
- `SessionMemoryManager.java` - Session management
